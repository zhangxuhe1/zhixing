# 知行 M2 iOS（内测二 · 公开与分享）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iOS 端实现 M2 全部体验：地点抽屉三段式（旅人故事/旅人镜头）、公开流与状态徽标、点亮/浏览、收藏/报错、旅程小结（建议→确认→分享长图）、当前位置选点，并清偿 M1 iOS 质量债。

**Architecture:** 延续 M1 结构（SwiftUI + @Observable store + APIClient 单例）。新增统一 `LoadState` 基建先行，后续新界面一律复用；公开内容照片复用 `AuthedPhotoView`（服务端已放宽 `GET /photos/:id` 授权）；分享长图纯客户端渲染（ImageRenderer + CoreImage 二维码）。

**Tech Stack:** SwiftUI（iOS 17+ / Swift 6）、MapKit、PhotosUI、CoreImage、CoreLocation；无新第三方依赖；xcodegen 管理工程。

**规格：** docs/superpowers/specs/2026-07-07-m2-design.md；**前置：** m2-server 计划全部完成（tag `m2-server`），本地 API 跑在 `http://localhost:8787` 且已 `pnpm -C packages/db seed --profile rich`。

## Global Constraints

- **本计划只定义接口与行为，不含可粘贴的实现代码**（M1 教训）。代码块仅限类型/签名/契约/测试用例表。
- 新增 .swift 文件后必须在 `apps/ios/` 目录跑 `xcodegen generate`（sources 按目录收集），重生成的工程文件一并提交。
- 单测跑法：`bash scripts/ios-test.sh`；每任务结束全量跑一次确认无回归再 commit。
- Swift 6 并发：新 store 一律 `@MainActor @Observable final class`，经 `.environment()` 注入（对齐 SessionStore/FootprintStore 模式）。
- 手动验证用 iPhone 17 模拟器；依赖 seed 数据的步骤先声明档位（rich/sparse）。dev 登录用 SignInScreen 的开发旁路入口（seed 用户 sub 形如 `seed-1`）。
- commit 信息中文，尾行 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`。
- 用户可见文案一律中文，语气克制（对齐现有「在此留足迹」风格）；错误文案不暴露技术细节。
- 打点（浏览）失败静默——不打扰用户是有意行为，其余网络错误必须可见可重试（LoadState）。
