# 知行 Mac 版安装说明

你好！这是「知行」的 Mac 内测版——一张有故事的中国地图：逛地图读风物故事，把去过的地方点亮成自己的足迹。感谢帮忙体验 🙌

## 系统要求

- macOS 14（Sonoma）及以上
- Apple Silicon（M 系列芯片）或 Intel 芯片的 Mac 都可以

## 安装

1. 双击打开 `Zhixing-0.3.0.dmg`；
2. 把「知行」图标拖进旁边的「应用程序」文件夹；
3. 弹出（推出）dmg，去「应用程序」里找「知行」。

## 首次打开（重要，只需操作一次）

这是未经 Apple 公证的个人开发内测版，第一次打开时 macOS 会拦一下。**根据你看到的弹窗**，按对应方式放行：

> ⚠️ 待实测确认：以下弹窗形态以首台干净机器实测为准，定稿时会更新本节。

**情况 A：弹「"知行"已损坏，无法打开」**（Apple Silicon 上大概率是这个）

这个对话框没有"仍要打开"的入口，别慌，App 没有真的损坏。打开「终端」（启动台里搜索"终端"），复制粘贴下面这一行并回车：

```sh
xattr -dr com.apple.quarantine /Applications/知行.app
```

然后正常双击打开即可，以后都不会再弹。

**情况 B：弹「无法验证开发者」类对话框**（Intel 机器上可能是这个）

1. 点「完成」（不要点"移到废纸篓"）；
2. 打开 系统设置 → 隐私与安全性，往下拉到底；
3. 在「安全性」一栏找到关于"知行"的提示，点「仍要打开」；
4. 输一次密码，之后就正常了。

**为什么会这样？** macOS 只对从浏览器/网盘/AirDrop 下载的文件做这道检查（叫 quarantine 隔离标记）。这个版本没有走 Apple 的公证流程（那需要付费开发者账号），所以被拦是正常的，放行一次即可。

**小技巧：** 如果 dmg 是用 **U 盘拷贝或 scp** 传给你的，就完全没有这道关卡，直接打开用就行。

## 使用提示

- **登录**：用邮箱验证码注册登录——输入邮箱 → 点「发送验证码」→ 去邮箱收 6 位验证码 → 填入登录。不需要 Apple 账号。收不到邮件时先翻一下垃圾箱。
- **批量导入照片**（Mac 版的核心玩法）：读取的是 Mac 上「照片」App 的图库。如果你平时照片都在 iPhone 上，建议在 Mac 的「照片」App 里登录同一 Apple 账号并开启 iCloud 照片——**刚开启后同步很慢，可能要等一阵子才有图**，属正常现象。
- **足迹默认仅自己可见**，想让别人看到需要主动公开并通过审核。

## 升级新版本时

以后拿到新版 dmg，直接覆盖安装即可。登录状态会保存在当前 macOS 用户的应用支持目录中，普通退出重开和覆盖升级都应继续保持；只有主动点击「退出登录」、会话过期或服务端主动失效时才需要重新验证。

> 当前无 Apple 开发者账号的 ad-hoc 内测版无法取得 Catalyst Keychain 所需 entitlement，因此暂用仅当前用户可读写（0600）的 Application Support 会话文件。以后换成合法稳定签名，App 会自动把会话迁回系统 Keychain 并删除该文件。
